The development preview for the active review branch was checked after the diversity-suggestion restoration. The default Pigeon / Pet-Companion optimized mix displays the restored green **Ingredient diversity** notice: “Try offering barley alongside this mix to increase diversity for your bird.”

The same preview also shows the new square **Suggest bird** control at the end of the bird row and the compact plus-only **Suggest profile** control beside the Current situation selector. These controls create research requests and do not alter calculator birds or profiles automatically.

The Pigeon / Pet-Companion Herbs & Supplements view was checked. Its profile cards and personalized supplement browsing omit Allium/garlic entries that are marked not eligible for automatic suggestion. The dedicated `/herbs` library displays an evidence-scope note and linked academic references on source-backed records, while retaining unlinked records as reference-only rather than automatic recommendations.

The Pigeon inventory picker still allows adzuki beans to be added so that the established cooked/prepared pathway remains available. After it is added, the inventory card is expected to show the new red raw-bean warning while leaving cooked/prepared guidance visible.
