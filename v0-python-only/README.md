# V0 Python-Only Calculator

This folder preserves the original Python-era calculator material from commit `24aa9c35` (`Add files via upload`), before the Vite/web-app repair represented by V2 and before the active multi-bird V3 application.

It is a historical reference, not the active application. Its original formulas, ingredient values, profiles, wording, and research documents are preserved without modification.

| File | Purpose |
|---|---|
| `pigeon_mix_calculator.py` | Original standalone pigeon mix calculator. |
| `pigeon_mix_calculator_v2.py` | Original alternate Python calculator version. |
| `expanded_ingredients.py` | Original expanded ingredients and supplements reference. |
| `test_calculator.py` | Original Python test scenarios. |
| `USER_GUIDE.md`, `RESEARCH_REFERENCES.md`, `bird_nutrition_research.md`, `calculator_design.md` | Original supporting documentation. |
| `V1_ORIGINAL_README.md` | Exact preserved copy of the original V1 README, kept here as a companion record of the earlier pigeon-only project description. |

## Run the preserved V0 calculator

```bash
python3 pigeon_mix_calculator.py
python3 test_calculator.py
```

The active browser application is [`../v3-webapp/`](../v3-webapp/). Do not edit V0 as part of ordinary V3 development.

## Original V1 README, preserved here

[`V1_ORIGINAL_README.md`](V1_ORIGINAL_README.md) is an exact copy of [`../v1-original/README.md`](../v1-original/README.md). It is included so anyone exploring the earliest Python-era material can also read the original pigeon-only project introduction without leaving V0. It is historical documentation, not a new set of current feeding instructions.
